# Alert catalog

Every alert rule in this stack, with an example of the Telegram message it sends.
Generated by `scripts/alert-catalog.py` from `prometheus/rules/*.yml` (PromQL) and `vmalert/rules/*.yml` (LogsQL), all evaluated by vmalert.
Severity: **critical** = loud message, repeated every hour; **warning** = silent message, repeated every 4 hours; **none** = never sent.
66 alerts. Rules whose exporter is not running have no data and never fire, so optional ones cost nothing.
