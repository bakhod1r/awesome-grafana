# Alert catalog

Every alert rule in this stack, with an example of the Telegram message it sends.
Generated by `scripts/alert-catalog.py` from `prometheus/rules/*.yml` (PromQL) and `vmalert/rules/*.yml` (LogsQL), all evaluated by vmalert.
Priority (label `priority`): **P1** = users affected now: loud, tags TELEGRAM_MENTIONS, repeated every 30m, ignores the maintenance window; **P2** = degraded or about to break: loud, tags, repeated every 1h; **P3** = working hours: silent, repeated every 24h; **info** = notice (deploys): silent, once. Each category goes to its own Telegram topic (label `category`).
68 alerts. Rules whose exporter is not running have no data and never fire, so optional ones cost nothing.
